# Chain2Pay

Chain2Pay is a payment gateway for online merchants. Buyers pay by card through a third-party on-ramp provider, and the merchant receives the payment in cryptocurrency in their own wallet.

This is the official GitHub account of Chain2Pay. The service is operated by Isthmus Business Group S.A. (Panama).

## Integrations

REST API with a sandbox, WooCommerce plugin, WHMCS module and white-label checkout. Plugins are distributed through the merchant dashboard.

## Fees

6% of each successful card payment, or 2.5% with the VIP plan (US$300 per 30 days). No setup fee. Details: https://chain2pay.is/pricing

## Official channels

Chain2Pay operates only the websites listed above. Any other website, account, repository or plugin using the Chain2Pay name is not operated by Chain2Pay.
